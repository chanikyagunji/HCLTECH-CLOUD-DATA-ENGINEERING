## 📌 Project Overview

This repository contains my **HCL Cloud & Data Engineering practical assignment**, demonstrating hands-on practice with SQL, Linux, Amazon Web Services (AWS), Microsoft Azure, and PySpark.

The assignment focuses on cloud infrastructure, data storage, ETL pipelines, database operations, security, automation, and data processing.

## 🎯 Objectives

- Practice SQL queries and database operations.
- Execute essential Linux commands.
- Understand AWS cloud services and data engineering workflows.
- Work with Azure cloud infrastructure and storage services.
- Explore ETL processes and data transformation using PySpark.
- Document practical implementations with screenshots and step-by-step procedures.

## 🔐 Security Best Practices

- Never upload passwords, API keys, access keys, or private credentials.
- Do not upload `.pem` private keys or sensitive configuration files.
- Avoid exposing virtual machines or databases directly to the public internet.
- Apply least-privilege access using IAM roles and Azure access controls.
- Remove temporary cloud resources after completing practical exercises to avoid unnecessary charges.
- Review screenshots for sensitive information before uploading them.
